# Vector Nodal Meshless Method in Three Dimensions (VNMM 3D)

This directory is designated for the upcoming 3D formulation and numerical implementation of the Vector Nodal Meshless Method (VNMM 3D), extending the 2D stabilized framework to three-dimensional vector electromagnetic problems in $H(\mathbf{curl}; \Omega)$.

## Planned Directory Structure:
- `src/`: Core 3D modules (tetrahedral/cloud support selection, 3D shape functions, 3D quadrature, and 3D Whitney edge FEM).
- `scripts/`: Executable benchmarks and validation scripts in 3D.
- `meshes/`: 3D nodal point clouds and tetrahedral benchmark meshes.
- `tests/`: Automated unit tests for 3D solvers and assembly routines.
